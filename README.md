obligatory to have installed:

kitty

fish

hyprland (obviously)

mako

nautilus

rofi

waybar

hyprshot

NetworkManager

Awww (You can also use hyprpaper for wallpapers but I recommend to use awww)


KEYBINDS:
SUPER + Q: Launch kitty

SUPER + C: Close app

SUPER + R: Universal rofi menu (put wallpaper in ~/Pictures/wallpaper)

SUPER + V: Enable floating

SUPER + F: Enable fullscreen

SUPER + I: Fullscreen screenshot

SUPER + SHIFT + I: Partial screenshot

SUPER + L: Reload waybar

SUPER + 1-9: Switch workspace

SUPER + SHIFT + 1-9: Move window to workspace
